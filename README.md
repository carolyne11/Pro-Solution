🖥️ Sistema de Acompanhamento de Bem-Estar do Colaborador

Aplicação Desktop – C# | Visual Studio | MySQL

📌 Descrição do Projeto

Este projeto consiste em uma aplicação desktop desenvolvida em C#, utilizando Visual Studio e banco de dados MySQL, com o objetivo de auxiliar empresas no acompanhamento do bem-estar emocional dos colaboradores, de forma organizada e segmentada por área.

O sistema permite que o colaborador registre, de maneira simples e confidencial, como está se sentindo no dia, possibilitando à empresa obter indicadores internos que apoiem ações de melhoria no ambiente de trabalho.

🎯 Objetivo

Fornecer à empresa uma visão analítica e preventiva sobre o clima organizacional, ajudando a identificar padrões de insatisfação, estresse ou sobrecarga por área, sem substituir avaliação médica ou psicológica.

⚙️ Funcionalidades
👤 Colaborador

Preenchimento diário do formulário de bem-estar

Registro do estado emocional no dia

Preenchimento de um questionário de autoavaliação

Possibilidade de acompanhar seus próprios registros

🏢 Empresa / Gestão

Acesso aos dados agrupados por área

Visualização de indicadores gerais de bem-estar

Identificação de áreas que demandam atenção

Apoio à tomada de decisão para melhorias internas

🧠 Questionário de Autoavaliação

O sistema inclui um teste de avaliação emocional, com o objetivo de identificar indícios de:

Estresse elevado

Ansiedade

Baixo bem-estar emocional

⚠️ Importante:
O questionário não realiza diagnóstico médico. Ele funciona apenas como uma ferramenta de apoio e prevenção, gerando indicadores para a empresa compreender melhor o cenário interno.
